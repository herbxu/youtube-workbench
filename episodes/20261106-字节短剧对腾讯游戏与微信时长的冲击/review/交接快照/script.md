# 红果动了腾讯哪块利润？

欢迎来到面朝北北。今天聊聊红果短剧。腾讯哪块利润最受影响？我看字节领跑，视频号能守住一席。

先看红果的规模。七月，红果日活达到一点六八亿。到了九月，一个月里用过它的人，约四点三亿。再看时长，七八月，红果用户的月人均单日使用时长，达到一百五十一分钟。

一天两个半小时，最容易挤掉的是哪段时间？先从同样靠观众追剧的腾讯视频说起。

先看腾讯视频。今天它单独赚多少，公开披露还算不出来。我们拿一笔假设的账试一试。原来一季收入一百，拍剧和买版权花一百一十，亏十。现在观众少了，收入只剩八十。

看这份已经签好的合同。观众可以随时换剧，腾讯答应付的钱，还得照付。如果成本只能从一百一十降到一百，那就从亏十变成亏二十。

可要是明年那几部回报差的剧还没签呢？把它们划掉，假设成本能降到七十。同样收八十，这回反而赚十。长视频最容易被分走时间，股东受多少影响，要看有多少支出真能省下来。

再看视频号。它的广告，腾讯已经列为高毛利收入。广告主把下一笔预算投给红果，腾讯少卖一个广告位，这笔原本能留下的利润，又有多少？

先看广告主怎么做决定。假设一家店原来在视频号投一千块钱。这个月又拿出一千块去红果试投。只要原来那笔还在，红果多接一单，腾讯就没有少收这一千块。

另一种情况是，店里总共就这一千块。它对了两边的订单，发现红果带来的新客户更便宜，于是下个月把钱挪走。此时即使用户照常打开微信，视频号这笔广告收入也确实受到了影响。

如果红果分走的是这类广告预算，意义就不同了。一个广告位少卖出去，平台的技术、研发和运营支出，并不会立即同比减少，所以收入减少可能较明显地传到利润。

具体幅度要看分成等可变成本。我更关心的是被分走收入原本能留下多少钱，而不是简单比较两个产品谁少了更多分钟。

接下来，为什么我会把视频号的广告看得更重？先翻腾讯二零二五年全年业绩公告，看看原本的利润从哪来。

增值服务贡献一半以上集团毛利，营销服务约占两成，金融科技及企业服务接近三成。这是看盈利结构的历史底数，竞争发生后怎么变，还要另外检验。

腾讯正在通过绿泡泡联合发行、视频号短剧分发和收入、流量激励争取内容。这给它提供了防守的机会。

但股东要核算两件事：有没有把微信外的用户时间带回来，以及这些时间在扣除分账和运营后，究竟留下多少回报。产品做起来，不代表这两笔账已经算得过来。

这里还有一种更隐蔽的风险。假如用户从视频号原来的内容，转去看微信里的免费短剧，总时长可能没有流失，广告收入也可能增加。

但如果新增分账和激励更高，净回报反而可能下降。反过来，若用更低成本的分发模式替代原来低回报的内容投入，回报也可能改善。迁移前后赚得怎样，比流量留在谁家更重要。

再往后看，我给短剧格局押一个方向：字节领跑，视频号站稳一块有利润的市场。像今天的短视频，但短剧多了一个变量：同一部剧，观众可以换个入口接着看。谁能留住下一部剧的观众，比谁抢到这一部爆款更重要。

我为什么更看好字节拿到最多观看？抖音适合发现一部剧，红果适合把它追完。对剧方来说，一个平台能试出什么开头吸引人，另一个能看出观众肯不肯看完。两端的反馈如果能用到下一部选剧上，这个优势才会累积。

视频号的机会在另一头。朋友把剧发进群，你点开就能看；看完还愿意点开下一部，腾讯才真的留下了你。绿泡泡和视频号已经试联合发行。我的检验很简单：激励降下来以后，剧方还来不来，观众还回不回，广告主还续不续。

不过，红果抢走的第一笔时间，也可能属于抖音自己。假设我今晚多看红果半小时，本来这半小时都用来刷抖音，那么字节合计一分钟也没多拿。假如红果多付了内容分账，还少了一次直播带货的机会，集团甚至可能少赚。

这让我想到当年的微信和手机 QQ。腾讯二零一三年年报里，年底微信与海外版合计月活账户三点五五亿，手机 QQ 的智能终端月活账户四点二六亿。两者同比都在增长。只看新产品做大，推不出老产品的用户已经等量搬走。

这个类比也有边界。微信能把联系人和支付习惯一起留下，一部短剧看完，观众下一次去哪儿却未必固定。要判断红果是不是给字节创造了新价值，我会看去重后的观看有没有增加，再看两边合计的广告和电商贡献，够不够覆盖新增的内容成本。

今年九月的笔记里，我已经注意到字节对腾讯内容业务的影响，但当时对游戏的判断是“没有被影响”。这只是当时的看法。

这次我会把问题拆细：随手消遣、靠广告变现的轻度游戏，更容易与短剧竞争；围绕竞技、朋友和长期进度形成的需求，替代难度更高。

想象晚上九点钟。刷了十分钟短剧，再点一局不需要约人的小游戏，这两件事可以互换。可要是四个朋友已经上线等我，今天不打，损失的是一起玩的机会。短剧能补上十分钟的消遣，却很难临时补上这四个人。

游戏则提醒我们，替代强弱和财务重要性甚至可能反过来。自研游戏是腾讯已经披露的高毛利收入来源。

成熟竞技和社交游戏不容易被短剧直接替代，但如果它们的付费或获客回报真的恶化，集团影响可能比一项薄利内容业务流失大量观看更大。所以核心游戏不能因为直接替代较弱，就从利润分析里靠后处理。

再往前算一步。少掉的如果是一批原本很少付费的路过玩家，时长曲线会先掉，收入未必等幅跟着掉。如果留下来的老玩家开始少买内容，或者新玩家越来越贵，时长看上去还行，现金回报也可能先变差。

再看九月的行业数据。二零二六年九月，手机游戏行业月人均使用时长，同比增长百分之三点五。这个数描述的是整个手机游戏行业。

对腾讯，还得回到单款游戏，分别看留存、付费和获客成本。行业平均数既不能证明一款游戏受了伤，也不能替它报平安。

还要拆开本土和海外。腾讯分别披露两者，红果的中国用户数据，不能推导全球游戏都同样受影响。对本土成熟游戏，看付费、留存与召回；

对新游戏，看获客投入能否收回；对小游戏平台，看腾讯实际获得的收入，不能把开发者全部流水算成腾讯利润。

我在笔记里写过一句话：护城河是局部的、相对的。微信恰好是个例子。朋友和工作联系还在那里，能保护通讯入口；但我回复完消息，可以继续去红果追剧。

关系链稳定，不等于娱乐广告也同样稳固。评价腾讯，要把这两种确定性分开，不能用自己熟悉微信的感受，替代对赚钱机制的研究。

比方说，我已经在便利店拿好一瓶水，打开微信去付款。昨晚少刷了两段视频，今天这瓶水大概还是会买。换个场景，我本来没有要买水，却在直播里看到一个新牌子下了单。这笔交易先要有人把我带到直播间。

金融科技及企业服务，原本就贡献腾讯相当一部分毛利。这不能全部算作微信支付，也不能都视为依赖刷视频。转账、已有购买意图的付款、理财与企业服务，受到红果的直接替代较弱；

直播和小店靠内容发现带来的新增交易，则更容易间接受影响。稳住这些已有生意，能缓冲内容竞争，但不保证所有新增交易都安全。

微信短剧还有两面性。原来付费剧方能赚到钱，就可能愿意买广告；免费平台改变回收方式后，这部分预算可能受压。

腾讯自己聚合免费短剧，则可能获得新的广告和分成机会。两边要放在一起算，扣掉内部替代和激励。剧方少赚的钱、腾讯少收的广告费和新平台的收益，不是同一个数字。

这也回到我的投资方法：以低于价值的价格买入，留出安全边际。但市场悲观，不自动代表便宜。

需要先算现有业务少赚多少、低回报投入能省多少、防守又要多花多少，再看价格反映了多少风险。这次还没有完成当前价格下的完整估值，所以不能从红果热度，直接跳到买入或者卖出。

所以，我更看好字节在短剧里领跑。视频号能不能守住一块赚钱的生意，我会看补贴少了以后，观众还回不回来，广告主还愿不愿意续投。

这里是面朝北北，一个专注于理解生意本质的价值投资频道。谢谢你看到这里，我们下期见，拜拜。
